# DREDGEWARD — Salvage the Sunken City

The city sank. Its gold did not. Pilot your salvage skiff, harpoon the wrecks, haul salvage to the buoy — and break THE ABYSSAL MAW on dive 8.

A complete original browser game for make.fun best-game-01: eight dives down the Sunken City, four enemy kinds (spike mines, volt eels, snapper crabs, ink squids), oxygen as the dive clock, a between-dive upgrade shop (Hull, Harpoon, Engine, Magnet — three tiers each), and a three-phase boss.

Play it: serve `game/` with any static server and open `game/index.html` in desktop Chrome. No network requests, no external files.

- WASD / arrows: steer the skiff. Mouse: aim the harpoon. Click / SPACE: fire and reel salvage.
- Bank salvage at the buoy (top centre) to count it toward the dive quota.
- Oxygen bubbles refill O2; repair kits fix the hull. 1–4: buy upgrades in the shop. ENTER: dive on.
- P: pause. M: mute. R: restart after the end screen.
- WIN: clear all 8 dives and break the Abyssal Maw. LOSE: hull hits 0 or oxygen runs out.
